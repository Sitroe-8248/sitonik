# Sitonik — Personal Portfolio

A responsive, static personal portfolio for Sitonik Kibet Rotich.

## Stack
- HTML, CSS and vanilla JavaScript
- No build tools, package manager or database required
- Designed to deploy on GitHub Pages or any static web host

## Local preview
Open `index.html directly in a browser.

## Deploy with GitHub Pages
1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Keep the `CNAME` file in the repository root for the custom domain.
5. At your domain registrar, configure the DNS records recommended by GitHub Pages and enable HTTPS after DNS verification.

## Content maintenance
Update the experience, education, skills and project sections in `index.html` when details change. Replace the GitHub avatar URL with a preferred professional headshot when ready.
